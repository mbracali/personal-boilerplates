# Catppuccin Palette Reference

A soothing pastel theme in four flavors. Source: <https://catppuccin.com/palette/>

Catppuccin ships four palettes that share the same **26 named colors** across two groups:

- **Accents (14):** Rosewater, Flamingo, Pink, Mauve, Red, Maroon, Peach, Yellow, Green, Teal, Sky, Sapphire, Blue, Lavender
- **Neutrals (12):** Text, Subtext 1, Subtext 0, Overlay 2, Overlay 1, Overlay 0, Surface 2, Surface 1, Surface 0, Base, Mantle, Crust

Pick one flavor per project and stick to its named roles — that's how themes stay consistent across apps.

| Flavor | Mood | Typical use |
|---|---|---|
| Latte | Light | Light mode / day |
| Frappé | Dark, muted | Soft dark mode |
| Macchiato | Dark, medium contrast | Balanced dark mode |
| Mocha | Darkest | High-contrast dark mode |

## Suggested semantic mapping

Use the same role names for every flavor so switching themes is a one-line change.

| Semantic role | Suggested Catppuccin name |
|---|---|
| Primary / links | Blue |
| Secondary | Lavender |
| Success | Green |
| Warning | Yellow |
| Danger / error | Red |
| Info | Sky |
| Notice / accent | Mauve |
| Highlight / CTA | Peach |
| Page background | Base |
| Sidebar / header | Mantle |
| Deepest bg / shadow | Crust |
| Cards, inputs, code bg | Surface 0 → Surface 2 |
| Borders, dividers | Overlay 0 → Overlay 2 |
| Muted / secondary text | Subtext 0, Subtext 1 |
| Body text | Text |

## CSS custom properties (Mocha example)

```css
:root {
  /* accents */
  --ctp-rosewater: #f5e0dc;
  --ctp-flamingo:  #f2cdcd;
  --ctp-pink:      #f5c2e7;
  --ctp-mauve:     #cba6f7;
  --ctp-red:       #f38ba8;
  --ctp-maroon:    #eba0ac;
  --ctp-peach:     #fab387;
  --ctp-yellow:    #f9e2af;
  --ctp-green:     #a6e3a1;
  --ctp-teal:      #94e2d5;
  --ctp-sky:       #89dceb;
  --ctp-sapphire:  #74c7ec;
  --ctp-blue:      #89b4fa;
  --ctp-lavender:  #b4befe;

  /* neutrals */
  --ctp-text:      #cdd6f4;
  --ctp-subtext-1: #bac2de;
  --ctp-subtext-0: #a6adc8;
  --ctp-overlay-2: #9399b2;
  --ctp-overlay-1: #7f849c;
  --ctp-overlay-0: #6c7086;
  --ctp-surface-2: #585b70;
  --ctp-surface-1: #45475a;
  --ctp-surface-0: #313244;
  --ctp-base:      #1e1e2e;
  --ctp-mantle:    #181825;
  --ctp-crust:     #11111b;

  /* semantic aliases */
  --color-bg:        var(--ctp-base);
  --color-bg-alt:    var(--ctp-mantle);
  --color-surface:   var(--ctp-surface-0);
  --color-border:    var(--ctp-overlay-0);
  --color-text:      var(--ctp-text);
  --color-text-mute: var(--ctp-subtext-0);
  --color-primary:   var(--ctp-blue);
  --color-success:   var(--ctp-green);
  --color-warning:   var(--ctp-yellow);
  --color-danger:    var(--ctp-red);
  --color-info:      var(--ctp-sky);
}
```

To switch flavors, redefine the `--ctp-*` block (e.g., under `@media (prefers-color-scheme: light)` use the Latte values). The semantic aliases stay the same.

## Notes on usage

- Stick to the named roles. Don't reach for a random hex — if it doesn't have a name, you're leaving the palette.
- Accents are **equal in weight**: pick one or two per view and use the rest sparingly for meaning (states, syntax).
- Contrast: Latte on Latte-Base passes WCAG AA for body text; verify accent-on-Base for buttons and links.
- Need more integrations (Tailwind, Figma, terminals, editors)? The catppuccin org on GitHub publishes official ports.
